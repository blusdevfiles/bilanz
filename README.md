# Bilanz

Kalorien-, Makro- und Gewichtstracker als installierbare Web-App. Alle Daten bleiben im Browser des Geräts (localStorage), es gibt keinen Server.

Installieren: Seite im Handy-Browser öffnen, dann „Zum Home-Bildschirm“ (iPhone: Safari › Teilen) bzw. „App installieren“ (Android: Chrome-Menü).
